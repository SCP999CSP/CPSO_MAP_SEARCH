# CPSO 数据库 — 命令行操作速查

从零开始复刻本项目时的完整命令清单。

---

## 1. 环境准备

### 安装 uv（如未安装）

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 克隆并进入项目

```bash
cd /path/to/CPSO_WEB_DATA
```

### 创建虚拟环境并安装依赖

```bash
uv sync
```

> 使用 `pyproject.toml` 与 `uv.lock`，Python 版本见 `.python-version`（3.10）

---

## 2. Docker 数据库

### 启动 PostgreSQL

```bash
docker compose up -d
```

> 或 `docker-compose up -d`（旧版）

### 查看运行状态

```bash
docker compose ps
```

### 停止

```bash
docker compose down
```

### 停止并删除数据卷

```bash
docker compose down -v
```

---

## 3. 数据库建表

### 首次建表 / 重建表

```bash
uv run python -m database.create_tables
```

或使用脚本：

```bash
bash scripts/init_db.sh
```

### 验证表是否创建

```bash
docker exec -it cpso_postgres psql -U postgres -d cpso_map -c "\dt"
```

应看到 `doctors`、`doctor_addresses`。

---

## 4. 连接数据库

### 进入 psql 交互

```bash
docker exec -it cpso_postgres psql -U postgres -d cpso_map
```

或使用脚本：

```bash
bash scripts/connect_db.sh
```

### 常用 psql 命令

```sql
\dt          -- 列出表
\d doctors   -- 查看表结构
\q           -- 退出
```

---

## 5. 环境变量

```bash
cp .env.example .env
```

编辑 `.env` 设置：

- `DATABASE_URL`：数据库连接串（默认已指向本地 Docker）
- `GOOGLE_GEOCODE_API_KEY`：**必填**，用于 `geocode.py` 调用 Google Geocoding API。勿将真实 Key 提交到 Git

---

## 6. 数据导入与 Geocoding

### 从 CPSO 抓取并写入数据库

编辑 `search_config.yaml` 配置 `postal_codes` 列表，然后运行：

```bash
uv run python search.py
```

若结果中某医生地址的邮编前四位与输入的 `postalCode` 不同，会写入 `search_postal_mismatch.yaml`。

### 附加地址（详情页抓取，可选）

`search.py` 会写入医生**主地址**，并在 `doctors` 表记录 CPSO 返回的 `additional_address_count`（附加营业点数量）。列表/搜索接口**不包含**各附加点的完整地址，需要单独从 CPSO 医生详情页抓取并写入 `doctor_addresses`（`is_primary = false`）。

**何时跑**：在至少完成一次 `search.py` 导入之后。脚本只处理 `additional_address_count > 0` 且「数据库里已有附加地址条数 ≠ 声明数量」的医生，其余跳过，减少无效请求。

在 `CPSO_WEB_DATA` 目录下：

```bash
uv run python fetch_additional_addresses.py
```

常用选项：

```bash
# 最多处理 N 个医生（调试）
uv run python fetch_additional_addresses.py --limit 10

# 只打印结果，不写数据库
uv run python fetch_additional_addresses.py --dry-run
```

附加地址入库后，其经纬度仍为空，需再跑 **`geocode.py`**，最后 **`export_to_json.py`** 才会出现在前端地图数据中。

---

### 地址 Geocoding（填充经纬度）

需在 `.env` 中设置 `GOOGLE_GEOCODE_API_KEY`，然后运行：

```bash
uv run python geocode.py
```

失败记录会写入 `geocode_failures.yaml`（医生+地址+最后尝试的查询地址）。

限制条数（测试用）：

```bash
uv run python geocode.py --limit 5
```

仅预览不写入：

```bash
uv run python geocode.py --dry-run
```

---

## 7. 导出数据给前端

将数据库中带经纬度的地址导出为 JSON，供 `frontend` 地图读取（仅导出 `latitude` / `longitude` 非空的记录）。

在 `CPSO_WEB_DATA` 目录下执行：

```bash
uv run python export_to_json.py
```

默认输出：`../frontend/public/doctors-addresses.json`。

常用选项：

```bash
# 只导出前 200 条（调试）
uv run python export_to_json.py --limit 200

# 指定输出路径
uv run python export_to_json.py -o /path/to/doctors-addresses.json
```

> 需已配置 `.env` 中的 `DATABASE_URL`（与 Docker 数据库一致）。若尚未 Geocoding，导出可能为空或很少；一般顺序为：`search.py` →（可选）`fetch_additional_addresses.py` → `geocode.py` → `export_to_json.py`。

---

## 8. 完整复刻流程（一键顺序）

```bash
# 1. 依赖
uv sync

# 2. 数据库
docker compose up -d

# 3. 建表
uv run python -m database.create_tables

# 4. 导入数据
uv run python search.py

# 4b. 附加地址（可选，需详情页抓取时）
uv run python fetch_additional_addresses.py

# 5. Geocoding（可选）
uv run python geocode.py

# 6. 导出 JSON 给前端地图
uv run python export_to_json.py
```
