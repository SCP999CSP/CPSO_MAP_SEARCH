# CPSO 数据库 — 命令行操作速查

从零开始复刻本项目时的完整命令清单。

---

## 1. 环境准备

### 安装 uv（如未安装）

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 克隆并进入项目

```bash
cd /path/to/CPSO_WEB_DATA
```

### 创建虚拟环境并安装依赖

```bash
uv sync
```

> 使用 `pyproject.toml` 与 `uv.lock`，Python 版本见 `.python-version`（3.10）

---

## 2. Docker 数据库

### 启动 PostgreSQL

```bash
docker compose up -d
```

> 或 `docker-compose up -d`（旧版）

### 查看运行状态

```bash
docker compose ps
```

### 停止

```bash
docker compose down
```

### 停止并删除数据卷

```bash
docker compose down -v
```

---

## 3. 数据库建表

### 首次建表 / 重建表

```bash
uv run python -m database.create_tables
```

或使用脚本：

```bash
bash scripts/init_db.sh
```

### 验证表是否创建

```bash
docker exec -it cpso_postgres psql -U postgres -d cpso_map -c "\dt"
```

应看到 `doctors`、`doctor_addresses`。

---

## 4. 连接数据库

### 进入 psql 交互

```bash
docker exec -it cpso_postgres psql -U postgres -d cpso_map
```

或使用脚本：

```bash
bash scripts/connect_db.sh
```

### 常用 psql 命令

```sql
\dt          -- 列出表
\d doctors   -- 查看表结构
\q           -- 退出
```

---

## 5. 环境变量

```bash
cp .env.example .env
```

编辑 `.env` 设置：

- `DATABASE_URL`：数据库连接串（默认已指向本地 Docker）
- `GOOGLE_GEOCODE_API_KEY`：**必填**，用于 `geocode.py` 调用 Google Geocoding API。勿将真实 Key 提交到 Git

---

## 6. 数据导入与 Geocoding

### 从 CPSO 抓取并写入数据库

编辑 `search_config.yaml` 配置 `postal_codes` 列表，然后运行：

```bash
uv run python search.py
```

若结果中某医生地址的邮编前四位与输入的 `postalCode` 不同，会写入 `search_postal_mismatch.yaml`。

### 地址 Geocoding（填充经纬度）

需在 `.env` 中设置 `GOOGLE_GEOCODE_API_KEY`，然后运行：

```bash
uv run python geocode.py
```

失败记录会写入 `geocode_failures.yaml`（医生+地址+最后尝试的查询地址）。

限制条数（测试用）：

```bash
uv run python geocode.py --limit 5
```

仅预览不写入：

```bash
uv run python geocode.py --dry-run
```

---

## 7. 完整复刻流程（一键顺序）

```bash
# 1. 依赖
uv sync

# 2. 数据库
docker compose up -d

# 3. 建表
uv run python -m database.create_tables

# 4. 导入数据
uv run python search.py

# 5. Geocoding（可选）
uv run python geocode.py
```
